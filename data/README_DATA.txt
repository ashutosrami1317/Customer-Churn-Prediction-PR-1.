DATA SOURCES
1. customers_csv.csv       : CSV source (400 records)
2. customers_json.json     : JSON source (250 records)
3. customers.db            : SQLite database with table 'customers' (200 records)
4. api_customers.json      : API response sample (158 records), served by api_server.py

The records are synthetic and created for educational practice. Missing values,
inconsistent categories, and duplicate rows are intentionally included so that
the cleaning steps can be demonstrated.
